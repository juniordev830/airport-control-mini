# Agendamento de pista

Protótipo Python de operações de pouso e decolagem com separação mínima configurável e detecção de conflitos.

Executar testes: `python -m unittest discover -s tests -v`.

Tempos são minutos inteiros; o módulo não representa regras reais de controle aéreo, meteorologia ou segurança operacional. Não utilizar em aviação real.
